# detail-type-filter

Let the reader choose which message types the conversation view shows.

Press `t` in a thread to open a panel listing prompts, replies, thinking, tool
calls, tool results, patches, summaries, and notes, each with its count. Space
toggles a row, `a` selects everything, `n` selects the conversation, `1` to `4`
select presets, `enter` applies, and `esc` cancels. The selection stays for the
rest of the session.
