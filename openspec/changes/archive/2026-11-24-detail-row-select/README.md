# detail-row-select

Make a conversation's messages look like rows you can see and pick.

Messages alternate between two dark background tints. In selection mode the
message under the cursor is tinted brighter with a `>` stripe on every line, and
`space` marks messages you want to keep, each with its own tint and a `#` stripe.
`y` copies the marked messages and `w` writes them to a file.
